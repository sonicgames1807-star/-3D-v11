# Mesh Scan Studio (MVP)

Локальное приложение для первичной обработки 3D-сканов. Интерфейс и обработка работают в браузере на вашем компьютере; модель не отправляется в сеть.

## Запуск

Требуется современный браузер с WebGL 2 (Chrome/Edge/Firefox) и Python 3 для локального сервера. В Windows можно запустить `run.bat`; подробная инструкция находится в `USER_GUIDE_RU.md`. Для ручного запуска из папки проекта:

```bash
python -m http.server 8000 --bind 127.0.0.1
```

Откройте `http://localhost:8000`. В Windows 10/11 достаточно установленного Python 3; установка npm-пакетов не нужна. Приложение пока поставляется как исходники, а не как собранный установщик.

## Реализовано

- Импорт STL (ASCII/binary), OBJ, PLY (ASCII/binary), OFF/COFF и glTF 2.0/GLB 2.0. Для glTF с внешними `.bin` выберите основной `.gltf` и его бинарные файлы вместе.
- WebGL 2: орбита ЛКМ, панорама ПКМ, масштаб колесом, вписывание и сетка. Большие сетки рисуются ускоренными порциями, интерфейс показывает прогресс до полной отрисовки.
- Диагностика числа вершин/треугольников, габаритов и граничных рёбер.
- Глобальное сглаживание двухпроходным двухшаговым Laplacian методом в Web Worker, сила/проходы, защита открытых границ и выраженных острых граней, отмена вычисления.
- Сглаживание кистью с радиусом, интенсивностью, плавным спадом и защитой острых граней; для больших сеток выбор поверхности и обработка одного клика выполняются в Web Worker.
- Упрощение: задайте только диапазон углов между соседними гранями. Алгоритм попарно схлопывает рёбра до отсутствия допустимых слияний; после каждого шага обновляет соседство. 0–180° разрешает все углы, но проверки безопасности остаются включены.
- Переключение исходной/текущей модели, отмена/повтор (до 8 действий, для крупных сеток — до 2), сброс к исходнику.
- Экспорт копии в binary STL, OBJ или ASCII PLY; исходный файл не перезаписывается.

## Ограничения MVP

- Лимит файла — 250 МиБ; предел геометрии — 4 000 000 треугольников и 12 000 000 вершин. Binary STL выше 100 000 треугольников разбирается в Web Worker. Для сеток выше 100 000 треугольников кисть работает по одному клику в фоне, упрощение и сглаживание — в фоне; каркас и точная диагностика открытых рёбер отключены, защита границ недоступна. Реальный предел зависит от свободной памяти браузера и видеокарты.
- Импорт поддерживаемых форматов сохраняет геометрию; OBJ/glTF/PLY-цвета, UV, материалы, текстуры, анимация и атрибуты не переносятся.
- Экспорт STL/OBJ/PLY содержит геометрию; единицы измерения и материалы не определяются.
- Упрощение сохраняет открытые края, проверяет локальную топологию, повторные грани и переворот треугольников. Не проверяет глобальные самопересечения и не гарантирует сохранение мелких деталей. На многомиллионных сетках граф соседства требует значительной памяти; обработку можно отменить.
- Кисть обрабатывает связную область внутри радиуса от ближайшей к попаданию вершины. Защита острых граней отключена по умолчанию и включается флажком. Если в радиусе нет вершин, увеличьте радиус; защищённые открытые края остаются неподвижны.
- Нет автоматического ремонта отверстий, исправления самопересечений, ретопологии, сохранения проекта или установщика Windows. Для больших сеток кисть работает кликами, не непрерывным перетаскиванием.
- Это MVP для базовой подготовки, не сертифицированная проверка готовности к 3D-печати.

## Форматы

| Формат   | Импорт                                            | Экспорт                     | Атрибуты                                                                |
| -------- | ------------------------------------------------- | --------------------------- | ----------------------------------------------------------------------- |
| STL      | ASCII и binary                                    | binary STL                  | Только треугольная геометрия                                            |
| OBJ      | вершины и полигоны, включая отрицательные индексы | вершины и треугольные грани | UV/MTL/текстуры/цвета не поддерживаются                                 |
| PLY      | ASCII/binary; также облака точек                  | ASCII PLY                   | Координаты и грани/точки; vertex colors не сохраняются                  |
| OFF/COFF | OFF/COFF                                          | —                           | Геометрия; цвета не сохраняются                                         |
| glTF/GLB | glTF 2.0; GLB 2.0                                 | —                           | Импорт геометрии и node transform; материалы/UV/анимация не сохраняются |

## Проверки

Автоматические проверки: `npm test`, `node tests/test_mesh.mjs` или `test.bat`. 11 регрессионных проверок: кисть, неизменность исходника, изоляция раздельных поверхностей, нулевая сила, сглаживание выступа, защита границ и ориентации, угловой фильтр, запрет повторных граней, лучевой выбор.

## Технологии и лицензии

Приложение использует браузерные WebGL 2, ES modules и Python только для локального статического HTTP-сервера; сторонние npm/Python-библиотеки не используются. Код приложения распространяется под MIT (см. `LICENSE`).
