# Архитектура

- `app.js`: интерфейс, история, импорт/экспорт и запуск фоновых операций.
- `viewer.js`: WebGL 2, камера и лучевой выбор.
- `mesh-core.js`: парсеры, геометрические операции, экспорт.
- `mesh-worker.js`: сглаживание, упрощение и кисть крупных моделей.
- `mesh-import-worker.js`: импорт крупных бинарных STL.

## Упрощение

Координаты хранятся в Float32Array тройками x/y/z, треугольники — в Uint32Array. Граф строится из рёбер треугольников через множества инцидентных граней. Пространственное совпадение не используется для слияния. Кандидаты сортируются по длине ребра; каждая операция объединяет только две соседние вершины. Измеряется двугранный угол актуальных граней. Проверяются link condition, открытые/немногообразные края, дубли и перевороты. После слияния обновляется граф; проходы повторяются, пока нет допустимых слияний. Интерфейс не задаёт процент. Параметр targetFaces сохранён только для программных вызовов как нижняя граница.

## Сглаживание

Глобальная обработка использует положительный и меньший отрицательный шаг Лапласа. Нормальная составляющая по умолчанию сохраняется: её удаление мешало сглаживать выступы. Нулевая сила ничего не меняет. Кисть выбирает связную область графа внутри сферического радиуса с плавным затуханием; защита острых граней опциональна. changed считает фактически перемещённые вершины.

## Ограничения

Глобальные самопересечения не проверяются. Открытые края упрощения фиксированы. Повреждённая топология не ремонтируется. Крупные графы требуют памяти и времени; миллионы треугольников в этой поставке не проверялись. Для обычного сглаживания/кисти защита границ доступна до 100 000 граней. Крупная кисть работает одиночными кликами. Радиус без вершин не даёт эффекта. Геодезическое расстояние не вычисляется, используется связность внутри сферы.

## Проверки

`npm test`: 11 регрессионных проверок в tests/test_mesh.mjs. Исходная поставка ссылалась на отсутствующую папку tests; теперь тесты входят в архив.

## Защита формы (проверка на креплении)

Каждое слияние ограничивает отклонение новой точки от плоскостей всех инцидентных граней величиной 0,00001 диагонали исходной модели. Это локальная защита, не глобальная гарантия расстояния до исходной поверхности. Перемещение кисти ограничено 2% радиуса, умноженными на силу и затухание.
